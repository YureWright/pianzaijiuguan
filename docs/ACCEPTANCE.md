
详细 JSON、截图和录像分别输出到 `test-results/acceptance/` 与 `test-results/empty-hand/`。交付 ZIP 的“验收证据”目录包含最终报告、截图和桌面/手机完整实玩录像。美术来源和完整提示词见 [ART-DIRECTION.md](ART-DIRECTION.md)。

## 验收范围

手机使用 Chrome 设备模拟，摄像头使用 Chromium 模拟设备，并验证真实 P2P 视频传输；未验证真实手机硬件或跨公网 TURN。浏览器系统语音在双页面测试中出现过启动或完成回调异常，启动保护与播放超时保护已自动释放等待，字幕保持可见；这不代表所有系统语音引擎都已兼容。付费大模型接口没有调用，适配测试使用本地接口。此版本尚未部署到公网。
